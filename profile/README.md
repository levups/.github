# Level UP Solutions

Two developers, Clément Joubert and Robert Maerten, building and running a French e-commerce platform. The Ruby
gems we depend on, we contribute to; the ones we could not make fast enough, we rewrote:

- [PrawnX](https://github.com/levups/prawnx): Prawn's API, rewritten for speed — same pages, lighter files
- [SlimX](https://github.com/levups/slimx): Slim templates, rewritten — faster, with a formatter and a linter
- [BrowserX](https://github.com/levups/browserx): the browser gem, faster, with a bot list that stays fresh
- [GretelX](https://github.com/levups/gretelx): breadcrumbs for Rails — namespaced, derived from your routes, checked
  in tests

PrawnX, SlimX and BrowserX are drop-in replacements for the gem they rewrite.
